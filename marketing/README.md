# โฟลเดอร์การตลาด (Marketing)

โฟลเดอร์นี้แยกไว้สำหรับงานแผนการตลาด/เนื้อหา/งานวิจัยของธุรกิจ AssetX Estate — **ไม่เกี่ยวกับโค้ดของแอป** (`src/`, `api/` ฯลฯ)

## ขอบเขตการทำงาน

- **Hermes Agent** ดูแลโฟลเดอร์นี้ทั้งหมด — วางแผนการตลาด, เขียนบทความความรู้เกี่ยวกับอสังหาริมทรัพย์/จำนอง/ขายฝาก, วางแผนโพสต์โซเชียล, ทำ research ตลาด
- **Claude Code** ดูแลส่วนโค้ด/ฟีเจอร์ของแอป (`src/`, `api/`, ฐานข้อมูล ฯลฯ) เหมือนเดิม — ไม่แก้ไฟล์ในโฟลเดอร์นี้เว้นแต่ถูกขอ

## โครงสร้างที่แนะนำ

```
marketing/
├── plan.md                  # แผนการตลาดโดยรวม (กลุ่มเป้าหมาย, ช่องทาง, งบประมาณ)
├── content-calendar/        # ปฏิทินคอนเทนต์รายเดือน
├── articles/                # บทความความรู้เกี่ยวกับอสังหาฯ/จำนอง/ขายฝาก (ต้นฉบับก่อนโพสต์)
├── research/                # สรุปงานวิจัยตลาด, ข่าวเศรษฐกิจ, แนวโน้มราคาอสังหาฯ
└── social/                  # ร่างโพสต์แยกตามช่องทาง (Facebook, LINE OA, Instagram ฯลฯ)
```

ไม่จำเป็นต้องทำตามเป๊ะ — Hermes ปรับโครงสร้างย่อยได้ตามความเหมาะสม ขอแค่ทุกอย่างอยู่ใต้ `marketing/` เพื่อไม่ให้ปนกับโค้ดแอป
