## 2. ช่องทางที่ควรใช้

| ช่อง | ภารกิจหลัก | เนื้อหาที่เหมาะ |
|------|------------|-----------------|
| **Facebook Page** | Brand awareness + Lead gen + Retargeting | Reels 15-60s, กดแชร์ได้, Carousel อธิบายขั้นตอน |
| **YouTube Channel** | 权威 educattion + Organic SEO | แปลงจากประเมินราคา/สัญญาจำนอง/ขายฝาก เป็นเนื้อหา 5-10 นาที |
| **TikTok** | ญBill leads ใหม่ + วิดีโอสั้น educational | 15-30s Hook + CTA ไปยัง landing page |
| **LINE OA** | Retainment + Appointment booking + Reminder | Broadcast คู่มือ, ลิงก์ผลประเมิน, รับนัดหมาย |
| **Google Search Ads** | สนใจ actively หา "จำนอง", "ขายฝาก", "ประเมินราคาบ้าน" | ลงโฆษณาคำค้นที่ตรงกับ funnel |
| **Instagram** | Visual storytelling + Trust building | Carousel/Stories แสดง case study หลังรุป |
| **เว็บไซต์/app ตัวเอง** | กลาง hub + Conversion | Form นัดหมาย, คำนวณประเมินออนไลน์, ดูสัญญา |

**ลำดับเริ่มต้นให้ต่ำงบ:**
1. Facebook Page + Reels/Shorts (ฟรี จัดทำเอง)
2. LINE OA (ฟรีเริ่มต้น)
3. Google Search Ads  budget เบาๆ (5–10k/เดือน)
4. YouTube (ฟรี จัดทำเอง)
5. Instagram (เชื่อมโยงกับ Facebook)
