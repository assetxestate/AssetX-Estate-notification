# ไอคอนในแถบท้ายโปสเตอร์

ไอคอนเหล่านี้ใช้โดย `scripts/make-contact-block.mjs` เพื่อสร้างบล็อกเบอร์/LINE (`public/contact-block-*.png`) ที่ `scripts/poster-footer.ps1` นำไปวางบนโปสเตอร์

- **`line-brand-icon.png`**
  - **ที่มา:** "Brand icon" ทางการของ LINE ดาวน์โหลดเมื่อ 9 พ.ย. 2569 จาก https://line.me/en/logo (ไฟล์ `LINE_Brand_icon.zip`)
  - **สิทธิ์:** LY Corporation เป็นเจ้าของสิทธิ์ทั้งหมด
  - **กติกาที่ต้องทำตาม:**
    - ใช้ไฟล์ตามต้นฉบับ ห้ามแก้สี ฟอนต์ หรือระยะ และห้ามใส่เอฟเฟกต์
    - เว้นพื้นที่ว่างรอบไอคอน
    - บนมือถือต้องสูงอย่างน้อย 40px
    - ห้ามวางบนพื้นหลังที่ทำให้มองไม่ชัด
  - **ห้ามแก้ไฟล์นี้** ถ้า LINE เปลี่ยนไอคอน ให้ดาวน์โหลดใหม่จากหน้าเดียวกัน
- **`phone-fill.svg`**
  - **ที่มา:** ไอคอน "phone" แบบ fill จาก Phosphor Icons (`@phosphor-icons/core@2.1.1`, `assets/fill/phone-fill.svg`)
