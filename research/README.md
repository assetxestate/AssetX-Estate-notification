# research/ — คอนฟิกระบบรีเสิร์ชโซเชียลและเทรนด์

โฟลเดอร์นี้คือ **คอนฟิก** ของเรดาร์ไอเดียคอนเทนต์ (ระบบ social-research · โปรไฟล์อสังหาฯ ขายฝาก/จำนอง)
แก้ไฟล์ในนี้ได้โดยไม่ต้องแตะโค้ด · โค้ดอยู่ `server/research/` · ตัวรันอยู่ `scripts/research-ideas.mjs` · คู่มือเต็ม [docs/social-research.md](../docs/social-research.md)

| ไฟล์ | คืออะไร |
|---|---|
| `idea_sources.json` | เลนข้อมูลทั้งหมด: คำค้น Google News · ฟีด/หน้าเว็บ · ช่อง YouTube · ประเภทย่อย (อายุ กลุ่ม cap) · สูตรคะแนน · คำตัดสินของเจ้าของ (`owner_decisions`) · มารยาทการดึง |
| `brand_facts.json` | ความจริงของแบรนด์ที่ AI ใช้ได้ (บริการ พื้นที่ ประเภททรัพย์ ขั้นตอน คำต้องห้าม นโยบายเครดิต) — ค่าที่เป็น `<...>` เติมใน `.local/research/brand_facts.local.json` (ไม่เข้า git) |
| `calendar.json` | ปฏิทินเหตุการณ์ (กนง. · ราคาประเมิน · มาตรการค่าโอน) เป็น ค.ศ. ISO เสมอ → ไอเดียล่วงหน้า + หน้าต่างคำค้น กนง. |
| `manual-checklist.md` | แหล่งที่ **ห้ามอัตโนมัติ** (ToS/บล็อกบอท/มีข้อมูลบุคคล) ให้คนดูเองแล้ววางลิงก์เข้าคิว |

ข้อมูลที่เก็บได้ (คิวไอเดีย) อยู่ในตาราง `marketing_ideas` บน Supabase (`supabase_marketing_ideas.sql`) ไม่ใช่ในโฟลเดอร์นี้
สถานะการรัน บันทึกรอบ และผล dry-run อยู่ `.local/research/` (gitignore)

กติกาที่ห้ามข้าม: อ่านอย่างเดียว · UA บอกชื่อบอท · เจอ 429/บล็อก = หยุด ห้ามเลี่ยง · ไม่เก็บข้อมูลบุคคล · ทุกอย่างเข้าคิวให้คนเลือก ไม่มีอะไรโพสต์เอง
