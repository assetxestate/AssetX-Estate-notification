# เช็กลิสต์แหล่งที่คนต้องดูเอง (ห้ามสคริปต์)

แหล่งเหล่านี้ **ห้ามดึงอัตโนมัติ** — ToS ห้ามสคริปต์ · บล็อกบอท (Cloudflare/Akamai) · หรือหน้ามีชื่อ/เบอร์/เลขคดีของบุคคล
วิธีใช้: เปิดดูตามรอบ → จดสรุปด้วยคำเราเอง (ไม่ลอกตาราง/กราฟ/เนื้อเต็ม) → วางหัวข้อ+ลิงก์เข้าคิวที่หน้า `/marketing` → ไอเดียวันนี้ → "เพิ่มไอเดียเอง"
(หรือ `POST /api/marketing-ideas {action:"manual", title, url, note}`) · ตัวรันจะเตือนรายการที่ถึงรอบในรายงานเทเลแกรม (จาก `calendar.json` kind=watch)

| แหล่ง | ทำไมห้ามอัตโนมัติ | ดูเมื่อไหร่ / ดูอะไร |
|---|---|---|
| **กรมธนารักษ์** (ประกาศราคาประเมิน · ข่าวกรม · assessprice) | นโยบายเว็บข้อ 3 ห้าม "การใช้วิธีการอัตโนมัติ (การใช้สคริปต์)" แม้ robots อนุญาต | **25 พ.ย.–5 ธ.ค. 2569** รอประกาศรอบ 2570–2573 · ค้นรายแปลงด้วยมือเฉพาะเคส ห้ามค้นจำนวนมาก · ห้ามอ้างตัวเลขจนประกาศจริง |
| **ราชกิจจานุเบกษา** | Cloudflare challenge ทุกหน้า | ยืนยันสถานะกฎหมาย/มาตรการ **ก่อนโพสต์ทุกครั้ง** (มาตรการค่าโอน · พ.ร.บ.ขายฝาก · ประกาศ ธปท.) |
| **REIC** (ข่าว + PDF ดัชนี) | ToS 2.1 ห้ามซอฟต์แวร์อัตโนมัติ · robots ห้าม `/upload` | รายไตรมาส (~8–12 และ ~26 ของเดือนถัดจากจบไตรมาส: ม.ค. เม.ย. ก.ค. ต.ค.) · เขียนด้วยคำเรา อ้าง "REIC" ห้ามลอกตาราง/กราฟ |
| **กรมบังคับคดี ค้นทรัพย์** (asset.led.go.th) | ท้ายเว็บห้ามนำไปใช้/ทำซ้ำ · มีชื่อคู่ความ เลขคดี | ไอเดีย/แนวโน้มด้วยคำเราเอง · ห้ามเก็บชื่อ เลขคดี (open data รายเดือนของกรม เลน `led_auction` ดึงอัตโนมัติอยู่แล้ว) |
| **Meta Ad Library** | **อัตโนมัติแล้ว 7 พ.ย. 2569** — เลน `ads` (`scripts/research-ads.mjs` สัปดาห์ละครั้ง · เจ้าของเลือกทาง ก.) อ่านข้อความแอดที่รันนานและให้ความรู้เข้าคิวไอเดีย · fetch ธรรมดาได้ 403 แต่ Chrome headless โปรไฟล์ชั่วคราว (ไม่ล็อกอิน) อ่านได้ | คนดูเองเฉพาะสิ่งที่เลนไม่เก็บ: ภาพ/วิดีโอ/แลนดิ้งเพจของแอดที่เข้าคิว (เปิดจาก `url` ของไอเดีย) · ลอกได้แค่แบบแผน ห้ามลอกเรต/ข้อความ/ภาพ · API ของ Meta ในไทยครอบคลุมเฉพาะโฆษณาการเมือง ใช้กับแอดธุรกิจไม่ได้ |
| **TikTok Creative Center** | ToS ข้อ 5 ห้าม automated scripts | ดูด้วยมือเดือนละครั้ง (อาจย้ายเป็น TikTok One) |
| **DDproperty** (Guides · Insight รายเดือน · Consumer Sentiment) | ToS + AUP ห้าม bot ชัดเจน | เดือนละครั้ง สรุปด้วยคำเรา · หัวประกาศมีชื่อนายหน้า/เจ้าของ ห้ามเก็บ |
| **Hipflat · LivingInsider · Home.co.th · ThinkofLiving · TerraBKK** | ToS ห้ามคัดลอก / บล็อกบอท / ToS อ่านไม่ได้ | หาราคาเทียบ (comps) ด้วยมือ เก็บแค่ตัวเลขรวม (บาท/ตร.ม. · จำนวน) |
| **ธนาคาร/AMC NPA** (BAM · SCB · KBank · กรุงศรี) | ข้อกำหนดห้ามใช้ข้อมูลเชิงพาณิชย์ / Akamai | โปรโมชัน NPA · โครงการนายหน้า NPA (เป็นโอกาสธุรกิจด้วย) |
| **เพจ Facebook ที่ไม่อยู่ในตัวเฝ้าเพจ** (ลิสต์เต็ม 47 เพจใน vault การตลาด `facebook-pages-watchlist.json` · ตัวเฝ้าเพจอ่าน 18 เพจใน `research/social_watch.json` ให้แล้วตั้งแต่ 3 พ.ย. 2569 — โควตา 4 เพจ/วัน ใช้ร่วมกับ DivisionX) | robots ของ Facebook ห้ามเก็บอัตโนมัติ · เจ้าของอนุมัติทางบัญชีสำรองแล้ว แต่โควตาบัญชีร่วมพออ่านได้แค่ 18 เพจ | ที่เหลือ 29 เพจ (ผู้พัฒนาโครงการ 9 · สื่ออีก 15 · ครีเอเตอร์ 2 · หน่วยงาน 1 ฯลฯ): สื่อ/ครีเอเตอร์เดือนละครั้ง · ผู้พัฒนาโครงการไตรมาสละครั้ง · จดเฉพาะแบบแผน (ฮุค ประเภทโพสต์ โครงเรื่อง) ห้ามจดชื่อ/เบอร์/ข้อความคนคอมเมนต์ · อยากให้ระบบอ่านเพจไหนเพิ่ม = สลับใน `social_watch.json` (อย่าเกิน 4 เพจ/วัน) |

## ข้าม (ไม่ต้องดู)

Kaidee (ToS 4.4–4.5 ห้าม robot + ข้อมูลผู้ขาย) · Thaihometown (ประกาศมีชื่อ/เบอร์ผู้ขาย · ข่าวเป็น PR) · Baania (บล็อกแม้ robots.txt) · FazWaz (ไม่ตรงกลุ่ม) · BOT API (ต้องสมัคร) · RSS กรมที่ดิน (มีแต่ข่าวบุคลากร) · Meta Ad Library API (ต้องยืนยันตัวตน · ในไทยครอบคลุมแค่โฆษณาการเมือง) · TikTok ทุกทางอัตโนมัติ (ทดสอบแล้วใช้ไม่ได้ ห้ามลองซ้ำ)

## ที่ยังไม่ได้ตรวจ (ตรวจก่อนเปิดเลน `tos: "pending"`)

ToS ของประชาชาติ / กรุงเทพธุรกิจ / SAM / กรมที่ดิน (เลนเปิดอยู่แต่ควรอ่าน · Pantip ตัดออกแล้ว 6 พ.ย. 2569 ไม่ต้องอ่าน) · Hipflat/FazWaz (Lifull Connect ตอบ 429) · LivingInsider/Baania · Meta Ad Library เปิดดูได้โดยไม่ล็อกอินไหม · TikTok Top Ads มีหมวดอสังหาฯ ไทยไหม · ฟีดหมวดอื่นของประชาชาติ (`/finance/feed`) · หน้า NPA กรุงศรี
