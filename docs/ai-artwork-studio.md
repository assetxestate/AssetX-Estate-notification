# AssetX AI Artwork Studio

## วิธีใช้งาน

1. เปิด การตลาด > สร้างโพสต์ และเลือกช่องทาง Facebook หรือ LINE OA
2. สร้างแคปชั่น แล้วกด ออกแบบภาพ AI หรือเข้ารออนุมัติและกดปุ่มเดียวกันบนโพสต์
3. กรอกรายละเอียดภาพ เลือกภาพถ่ายธรรมชาติหรือโมเดลสถาปัตยกรรม แล้วกด สร้างภาพ AI
4. ใช้ เลือกภาพจริง เพื่ออัปโหลด JPG, PNG หรือ WebP ได้เช่นกัน
5. แก้หัวข้อ รายละเอียดสั้น ข้อความติดต่อ ชุดสี รูปแบบ และการครอป
6. เลือกขนาด 1080 x 1350 หรือ 1080 x 1080 แล้วตรวจภาพตัวอย่าง
7. กด บันทึกและแนบกับโพสต์ จากนั้นตรวจอนุมัติและตั้งเวลาในคิวตามปกติ

การสร้างภาพไม่เผยแพร่ไปยัง Facebook ทันที การเปลี่ยนข้อความหรือสีไม่เรียก AI ซ้ำ
ใช้ภาพถ่ายจริงสำหรับประกาศทรัพย์เฉพาะรายการ ภาพจาก AI มีข้อความกำกับว่า ภาพประกอบ AI

## การจัดเก็บและแก้ไข

แต่ละภาพเก็บไฟล์ JPG สำเร็จ ภาพต้นฉบับ และค่าจัดหน้าไว้ใน mediaAssets ของ workspace เดิม
โลโก้อ้างอิง public/logo.jpg ส่วนข้อความไทยจัดวางด้วย Canvas และฟอนต์ Tahoma ในเครื่อง
ภาพจะถูกย่อก่อนเก็บและส่งต่อไฟล์สำเร็จผ่าน Facebook API ที่มีอยู่
เมื่อแก้ภาพในหน้ารออนุมัติ โพสต์จะกลับมารอตรวจอีกครั้ง
ยังไม่มีการแก้ไขภาพของโพสต์ที่ส่งไป Facebook แล้ว

## การตั้งค่าบริการ

ใช้ OPENAI_API_KEY, OPENAI_IMAGE_MODEL และ OPENAI_IMAGE_QUALITY ฝั่งเซิร์ฟเวอร์เดิม
โหมด artwork-background ขอภาพประกอบสี่เหลี่ยมจัตุรัสโดยไม่มีข้อความหรือโลโก้
โปรแกรมนำภาพมาครอปและวางข้อความไทยกับโลโก้ต้นฉบับแยกภายหลัง
เมื่อบริการสร้างภาพล้มเหลว โปรแกรมแสดงข้อผิดพลาดและยังเก็บภาพเดิมไว้
ค่าใช้จ่ายการสร้างภาพขึ้นกับบัญชี API ที่ตั้งไว้ จำนวนเครดิตในแถบหัวระบบเดิมไม่ได้เป็นยอดโควต้า API

## ผลตรวจ 29 กันยายน 2569

- Build และชุดทดสอบ API ผ่าน
- ทดสอบเบราว์เซอร์ desktop/mobile ด้วยภาพทดสอบ: เปลี่ยนขนาด ข้อความ สี การเปิดกลับมาแก้ และตรวจไม่ล้นหน้าจอ
- ทดสอบตั้งแต่แนบภาพ > อนุมัติ > คำขอ Facebook โดยจำลองปลายทาง ไม่เผยแพร่โพสต์จริง
- บริการสร้างภาพจริงด้วย API key ใน .env.local ตอบ 429 / OPENAI_IMAGE_QUOTA_EXCEEDED ต้องตรวจ billing หรือ quota ของบัญชีนั้น
- ตรวจ Production หลัง deploy แล้ว: API ตอบ OPENAI_IMAGE_FAILED เพราะยังไม่ได้ตั้ง OPENAI_API_KEY บน server
- ขั้นถัดไป: เพิ่ม OPENAI_API_KEY ที่มี billing/quota พร้อมใช้ใน Vercel > assetx-estate > Settings > Environment Variables > Production แล้ว Redeploy และทดสอบสร้างภาพอีกครั้ง ไม่ส่งคีย์ผ่านแชตหรือ commit ลง Git
