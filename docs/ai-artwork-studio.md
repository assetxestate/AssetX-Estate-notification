# AssetX AI Artwork Studio

## วิธีใช้งาน

1. เปิด การตลาด > สร้างโพสต์ และเลือกช่องทาง Facebook หรือ LINE OA
2. สร้างแคปชั่น แล้วกด ออกแบบภาพ AI หรือเข้ารออนุมัติและกดปุ่มเดียวกันบนโพสต์
3. กรอกรายละเอียดภาพ เลือกภาพถ่ายธรรมชาติหรือโมเดลสถาปัตยกรรม แล้วกด สร้างภาพ AI
4. ใช้ เลือกภาพจริง เพื่ออัปโหลด JPG, PNG หรือ WebP ได้เช่นกัน
5. แก้หัวข้อ รายละเอียดสั้น ข้อความติดต่อ ชุดสี รูปแบบ และการครอป
6. เลือกขนาด 1080 x 1350 หรือ 1080 x 1080 แล้วตรวจภาพตัวอย่าง
7. กด บันทึกและแนบกับโพสต์ จากนั้นตรวจอนุมัติและตั้งเวลาในคิวตามปกติ

การสร้างภาพไม่เผยแพร่ไปยัง Facebook ทันที การเปลี่ยนข้อความหรือสีไม่เรียก AI ซ้ำ
ใช้ภาพถ่ายจริงสำหรับประกาศทรัพย์เฉพาะรายการ ภาพจาก AI ไม่มีป้ายกำกับบนภาพ (เจ้าของสั่งเอาป้าย ภาพประกอบ AI ออก 6 พ.ย. 2569)

## โปสเตอร์จาก ChatGPT (คอมสำนักงาน)

ปุ่ม สร้างโปสเตอร์ด้วย ChatGPT ในหน้าต่างออกแบบภาพ ส่งหัวข้อและเนื้อหาโพสต์เข้าคิว
คอมสำนักงานที่ล็อกอิน Codex ด้วย ChatGPT Plus หยิบงานไปสร้างโปสเตอร์พร้อมข้อความไทย แล้วส่งภาพกลับขึ้นเว็บเอง
ไม่ใช้ OPENAI_API_KEY และไม่มีค่า API แยก ทุกภาพนับโควตาของแพ็กเกจ ChatGPT

1. เลือก ขนาดภาพตามแพลตฟอร์ม ก่อนกดสร้าง: ฟีด 4:5 · จัตุรัส 1:1 · Story/Reels/TikTok 9:16 · ภาพลิงก์ 1.91:1 · ปก YouTube 16:9
2. กด สร้างโปสเตอร์ด้วย ChatGPT แล้วรอประมาณ 1–2 นาที ปิดหน้าต่างระหว่างรอได้ เปิดใหม่แล้วระบบตามงานต่อ
3. ภาพที่ได้ใช้รูปแบบ โปสเตอร์สำเร็จรูป · เต็มภาพ ปรับให้ได้ขนาดพิกเซลตามที่เลือก (ค่าเริ่มต้นย่อให้เห็นครบ เติมขอบเบลอ หรือเลือกครอปเต็มกรอบ)
4. ตรวจตัวสะกดภาษาไทย ปรับ ตำแหน่งครอป ถ้าจำเป็น แล้วกด บันทึกและแนบกับโพสต์ ตามเดิม

ChatGPT สร้างภาพได้ 3 สัดส่วน (ตั้ง 2:3 · จัตุรัส · นอน 3:2) ขนาดที่สัดส่วนไม่ตรงจะสั่งให้วางข้อความในพื้นที่ปลอดภัยกลางภาพ แล้วครอปขอบออกประมาณ 8–11% ต่อด้าน

### ระบบออกแบบโปสเตอร์ (v3.2 "เนื้อหาเป็นพระเอก" · 7 พ.ย. 2569)

ถอดจากตัวอย่างโปสเตอร์ 8 ภาพที่เจ้าของชอบ แล้วแปลงเป็นโทนของ AssetX ไว้ที่ src/lib/posterDesignSystem.js (ไฟล์เดียว ใช้ทั้งคิว ChatGPT ปุ่มสร้างภาพบนเว็บ และ API /api/marketing-image)
ประวัติวันเดียว: v2 (เช้า) แถบ 5 ชั้น เจ้าของติว่าไม่สะดุดตา ไม่มีจุดโฟกัส องค์ประกอบใหญ่ โลโก้วางไม่เป็นมืออาชีพ → v3 ทีมวิจารณ์ 3 มุมวัดตัวอย่างเป็นเปอร์เซ็นต์ของภาพ ให้ผู้แนะนำเป็นจุดโฟกัส → v3.2 เจ้าของกำกับว่า "คนมีหรือไม่มีก็ได้ เน้นเนื้อหา มองภาพแล้วรู้เลยว่าโพสต์สื่ออะไรและให้ประโยชน์อะไร" จึงให้เนื้อหาเป็นจุดโฟกัส คนเป็นตัวเลือกในโซนเล็ก

- หลักข้อเดียว: คนที่เห็นแค่ภาพต้องรู้ว่าโพสต์เรื่องอะไร ประเด็นหลักคืออะไร และควรทำอะไรต่อ โดยไม่ต้องเปิดแคปชั่น (prompt มี READABILITY TEST ให้โมเดลตรวจเอง)
- โซนบนลงล่าง: พาดหัว 2 บรรทัดชิดซ้ายใน 62% ซ้าย (ไล่สี ขอบน้ำเงิน นูน 3D เอียง -2° เน้น "ทั้งคำ" ที่ระบบเลือกให้จากคลังคำโดเมน เช่น ค่าใช้จ่าย โฉนด มิจฉาชีพ — โมเดลเคยเน้นแค่พยางค์) → ริบบิ้นประโยชน์ (วลีครบ 4–10 คำจากโพสต์ว่าผู้อ่านได้อะไร) → การ์ดหลักเต็มความกว้าง 34–46% ของภาพ: ป้ายหัวข้อ + 3–5 แถว แต่ละแถว = หัวข้อ 3–7 คำ + รายละเอียด 8–18 คำ คัดจากจุดเดียวกันของโพสต์ (แถวละเครื่องหมายเดียว) → แผงลงมือทำ 2–3 ข้อ (ควรทำ/ควรเช็กอะไร) → กล่องเตือน (ถ้ามี) → แถบล่างน้ำเงินบางชิดเส้นตัด มีปุ่ม "ติดต่อ AssetX Estate"
- โซนฮีโร่: มุมขวาบน 36% กว้าง × 24% สูง ข้างพาดหัว ใส่กลุ่มภาพถ่ายตามหัวข้อ (เอกสาร+ปากกา · บ้าน · ที่ดิน · เหรียญ) หรือผู้แนะนำแค่ช่วงไหล่ขึ้นไป (เฉพาะโพสต์เชิงคำแนะนำ) ห้ามล้ำลงมากินพื้นที่เนื้อหา
- ตัวอักษร 3 ระดับ: พาดหัว 7.5–8.5% ของภาพ · หัวข้อแถว/ริบบิ้น/เลข 2.6–3.2% · รายละเอียด/ปุ่ม 2.1–2.4% (ไม่เกิน 32 px ที่กว้าง 1080)

## โหมดอิสระ: ให้ Codex ออกแบบเอง (7 พ.ย. 2569 ดึก · ค่าเริ่มต้นตั้งแต่ 8 พ.ย. 2569)

- **รูปเจ้าของในภาพหลัก + ไม่มีป้าย "ภาพประกอบ" (10 พ.ย. 2569):** เจ้าของเห็นภาพทดสอบแล้วขอ "เอารูปผมไปใส่ในโปสเตอร์แทน" และให้เอาคำว่า ภาพประกอบ ออกจากภาพ → ตัวรับงานแนบ `.local/poster-refs/presenter/presenter-cut.jpg` เป็นภาพที่ 1 (THE ADVISOR: หน้า ทรงผม สีผิว เสื้อเชิ้ตขาวเดียวกัน ไม่เอาฉากหลัง ป้าย ไมค์หนีบ) ตามด้วยเรฟสไตล์เป็นภาพที่ 2 (ห้ามลอกป้ายบนภาพถ่ายและคนในเรฟ) · ภาพหลักมีเจ้าของเป็นผู้แนะนำฝั่งเจ้าของทรัพย์ (อธิบาย ดูเอกสาร หรือมองผู้ชม) ห้ามเป็นลูกค้า คนรับเงิน หรือฉลอง · เป็นหน้าเดียวที่ชัด คนอื่นเห็นแค่ด้านหลังหรือเบลอ · แผนข้อความต้องเขียน `brief.hero` ที่มี "the advisor" (ไม่มี = ปัญหาเบา ขอแก้) และห้ามบรรยายหน้าตา · ไม่มีไฟล์รูป = ภาพหลักไม่มีหน้าคนเลย · บรรทัด MODE มี `presenter=use|none` · ไม่มีบรรทัดป้ายภาพแล้ว และรายการห้ามมี "caption, tag or label on the photograph"
- **ข้อความไม่ใช่คำต่อคำ** (ต่างจากโหมดอิสระ/ตามเรฟ): ย่อจากโพสต์เหมือนที่ Codex ทำให้ภาพต้นแบบ — ตรวจคำบนภาพก่อนโพสต์ทุกครั้ง · แผนและคำสั่งภาพของแต่ละงานเก็บที่ `.local/image-jobs/job-<id>-premium.json`
- **โครงภาพหมุนเวียน 5 แบบ** (เจ้าของ 11 พ.ย. 2569 หลังเห็น #37 กับ #32 โครงเดียวกัน "ดูซ้ำและน่าเบื่อ") · `PREMIUM_LAYOUTS` ใน `src/lib/posterPremium.js`:
  - `classic` ภาพหลักด้านบน 35–40% + ข้อ 01-03 เรียงลง (คำสั่งเดิมทุกตัวอักษร)
  - `split` ข้อความคอลัมน์ซ้ายเป็นเช็กลิสต์ + ภาพสูงเต็มด้านขวา
  - `cards` พาดหัวกึ่งกลาง + แถบภาพกลาง + ข้อเป็นการ์ดเรียงแถว (4 ข้อ = 2×2)
  - `overlay` ภาพเต็มใบโทนเข้ม ไล่สีน้ำเงินด้านซ้าย + ข้อบนแผงกระจกฝ้า (ตัวหนังสือขาว สีเน้นเฉดอ่อน)
  - `steps` พาดหัวทับภาพหลัก + ข้อเป็นขั้นตอนแนวนอน (ไม่ใช้เมื่อมีแถบกระบวนการกลางภาพ)
  - ตัวรับงานเลือกด้วย seed และเลี่ยงโครงของ 2 งานพรีเมียมล่าสุด (อ่าน `layout` ในไฟล์ `.local/image-jobs/job-<id>-premium.json` · ไฟล์ก่อน 11 พ.ย. = classic) · ข้อความ รูปผู้แนะนำ แถบ CTA ชิดล่าง และกติกาแบรนด์เหมือนกันทุกโครง · log บอก `โครง <id>`
  - กด "สร้างใหม่" ที่โพสต์เดิมได้โครงใหม่ · ถ้าโครงไหนออกมาไม่ดีซ้ำ ๆ เอาออกจาก `PREMIUM_LAYOUTS` ได้ (แล้วรีสตาร์ตตัวรับงาน)
- **พาดหัวบนการ์ดร่างพิมพ์แก้เองได้** (11 พ.ย. 2569): ภาพพรีเมียมมักได้พาดหัวที่ AI ย่อให้คมกว่า (เช่น #37 "ติดภาระเดิม เริ่มคุยก่อนได้") — พิมพ์ลงช่อง "พาดหัว" เหนือแคปชั่นได้ ใช้เป็นหัวข้อของภาพรอบถัดไปด้วย · แก้แล้วต้องอนุมัติใหม่

## คลังภาพอ้างอิงจากเทเลแกรม (7 พ.ย. 2569)

เจ้าของเก็บโปสเตอร์ของคู่แข่งไว้เป็น "โครงอ้างอิง" ให้โมเดลดูจังหวะการจัดวาง ไม่ลอกข้อความ สี หรือโลโก้ของเขา (ทดสอบแล้ว 7 พ.ย.: คำสั่งแบบบีบสั้นตามสคีมาของสกิล Codex + ภาพอ้างอิง 3 ภาพ ให้ภาพเหมือนกันทั้งจากคิวและจากแอป ChatGPT ที่ตั้งคุณภาพ High)

วิธีส่งรูปเข้าคลัง: ส่งรูปหรือไฟล์ jpg/png เข้าห้องบอท AssetX ในเทเลแกรม พร้อมคำว่า **รูปตัวอย่าง** ในคำบรรยาย (ต่อท้ายด้วยหมายเหตุสั้น ๆ ว่าชอบตรงไหนได้ เช่น "รูปตัวอย่าง ชอบการ์ดเทียบสองฝั่ง") ส่งเป็นอัลบั้มหลายรูปได้ ใส่คำนำในรูปใดรูปหนึ่งก็พอ บอทตอบกลับว่ารับกี่ภาพ

- `api/telegram-webhook.js` → `server/poster-refs.js`: ดาวน์โหลดไฟล์จาก Telegram อัปโหลดขึ้น bucket `marketing-images` ใต้ `poster-refs/` และเพิ่มแถวในตาราง `poster_refs` (status `new`) · รูปในอัลบั้มที่มาก่อนคำบรรยายเก็บเป็น `unclaimed` แล้วยกเป็น `new` เมื่อคำบรรยายมาถึง · รูปเดี่ยวที่ไม่มีคำนำไม่เก็บ
- `scripts/image-worker.mjs` บนคอมสำนักงานดึงแถว `new` ลง `.local/poster-refs/inbox/` ทุก 20 วินาที ชื่อไฟล์ `วันที่-เลขแถว-หมายเหตุ.jpg` พร้อมจดใน `notes.jsonl` แล้วตั้ง `fetched` · ถ้ายังไม่ได้รัน SQL จะพัก 10 นาทีแล้วลองใหม่ ไม่กระทบคิวภาพ · `npm run image-worker -- --check` บอกจำนวนรูปที่รอดึง
- ตั้งค่าครั้งแรก: รัน `supabase_poster_refs.sql` ใน Supabase SQL Editor (ต้องมี bucket จาก `supabase_marketing_image_jobs.sql` ก่อน) · Vercel ต้องมี `SUPABASE_SERVICE_ROLE_KEY` และ `ASSETX_TELEGRAM_BOT_TOKEN` (มีอยู่แล้ว) · คอมสำนักงานดึงโค้ดใหม่แล้วเปิดตัวรับงานอีกครั้ง
- การจัดหมวด (ข้อเลขลำดับ · เช็กลิสต์ · เทียบสองฝั่ง · ถาม-ตอบ · ข้อควรระวัง) ยังทำมือโดย Claude เมื่อเจ้าของสั่ง และโฟลเดอร์ `.local/poster-refs/` ไม่ขึ้น git เพราะเป็นภาพของคู่แข่ง · หมายเหตุผ่านตัวลบข้อมูลบุคคลก่อนเก็บ · ไม่มี DELETE (รูปที่ไม่ใช้ตั้ง `dismissed`)

## การจัดเก็บและแก้ไข

แต่ละภาพเก็บไฟล์ JPG สำเร็จ ภาพต้นฉบับ และค่าจัดหน้าไว้ใน mediaAssets ของ workspace เดิม
โลโก้อ้างอิง public/logo.jpg ส่วนข้อความไทยจัดวางด้วย Canvas และฟอนต์ Tahoma ในเครื่อง
ภาพจะถูกย่อก่อนเก็บและส่งต่อไฟล์สำเร็จผ่าน Facebook API ที่มีอยู่

## การตั้งค่าบริการ

ใช้ OPENAI_API_KEY, OPENAI_IMAGE_MODEL และ OPENAI_IMAGE_QUALITY ฝั่งเซิร์ฟเวอร์เดิม
โหมด artwork-background ขอภาพประกอบสี่เหลี่ยมจัตุรัสโดยไม่มีข้อความหรือโลโก้
โปรแกรมนำภาพมาครอปและวางข้อความไทยกับโลโก้ต้นฉบับแยกภายหลัง
เมื่อบริการสร้างภาพล้มเหลว โปรแกรมแสดงข้อผิดพลาดและยังเก็บภาพเดิมไว้
ค่าใช้จ่ายการสร้างภาพขึ้นกับบัญชี API ที่ตั้งไว้ จำนวนเครดิตในแถบหัวระบบเดิมไม่ได้เป็นยอดโควต้า API
