# การร่างและตรวจคอนเทนต์ AssetX

## สิ่งที่แก้

- ส่งหัวข้อจาก Studio ถึงตัวร่างจริง และเก็บหัวข้อต้นทางกับโพสต์
- แยกแม่แบบซื้อทรัพย์ ขายทรัพย์ ขายฝาก จำนอง เปรียบเทียบสัญญา และสภาพคล่อง
- ใช้หมวดเดียวกันสำหรับแคปชั่น ภาพ สคริปต์ และแฮชแท็ก ไม่หยิบข้อเสนอขายฝากของแบรนด์มาแทนหัวข้อซื้อที่ดิน
- ไม่ตรวจข้อความคำสั่งใน campaignContext ราวกับเป็นข้อความโฆษณาที่จะเผยแพร่
- แยกผลตรวจเนื้อหาออกจากสถานะอนุมัติ ตรวจซ้ำเมื่อกดอนุมัติและก่อนส่ง Facebook ฝั่งเซิร์ฟเวอร์
- การแก้แคปชั่นหรือช่องทางทำให้ต้องอนุมัติใหม่
- คะแนนโครงสร้างไม่ใช่คะแนนความถูกต้องของข้อเท็จจริง

## วิธีตรวจงาน

1. สร้างโพสต์หัวข้อ `ข้อควรรู้ก่อนซื้อที่ดินเปล่า ทั้งทำเลทอง`
2. ตรวจว่ารายการเป็นเอกสารสิทธิ์ ทำเล/ทางเข้าออก และราคา/ค่าใช้จ่าย ไม่มียอดสินไถ่
3. ส่งรออนุมัติ ผลตรวจเบื้องต้นผ่านได้ แต่สถานะต้องยังเป็นรอตรวจ
4. หากเติมข้อความรับประกันอนุมัติ หรือเติมสินไถ่ในเรื่องซื้อที่ดิน ต้องกดอนุมัติไม่ผ่าน
5. แก้ข้อความแล้วตรวจอีกครั้ง การส่ง Facebook ยังต้องได้รับอนุมัติจากคน

## ข้อจำกัด

ระบบนี้ยังเป็นแม่แบบและกฎตรวจข้อความ ไม่ใช่เครื่องตรวจข้อเท็จจริงหรือที่ปรึกษากฎหมาย
หัวข้อที่ไม่รู้จักจะให้ร่างแจ้งข้อมูลไม่เพียงพอและไม่อนุญาตให้เผยแพร่ผ่านขั้นตอนนี้
ข้อความหัวข้อจากผู้ใช้ยังต้องตรวจข้อกล่าวอ้างด้วยคน แม้คะแนนโครงสร้างสูง
ต้องตรวจเอกสาร แหล่งอ้างอิง ตัวเลข สิทธิใช้รูป และความยินยอมสำหรับเคสจริงก่อนอนุมัติ
ไม่มีการค้นข้อมูลกฎหมายหรือข่าวล่าสุดอัตโนมัติ และไม่มีการเรียก AI ที่มีค่าใช้จ่ายในตัวร่างนี้
ร่างเก่าไม่ถูกเขียนทับอัตโนมัติ ควรสร้างร่างใหม่จากหัวข้อต้นทางเมื่อพบข้อความปนเรื่อง
การทดสอบใช้ข้อมูลจำลอง ไม่แก้ฐานข้อมูล Production และไม่เผยแพร่ Facebook จริง
