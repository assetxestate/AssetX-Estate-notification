# สรุปประจำวัน · 17 พ.ย. 2026

> เจ้าของบอกว่าสัญญาที่บริษัทปล่อยเงินเองต้องแยกจากสัญญาของนายทุน เพราะดอกเบี้ยเข้าคนละบัญชี
> Dashboard มีการ์ด "รายรับดอกเบี้ย แยกตามเจ้าของเงินทุน" แล้ว (ขึ้นเว็บแล้ว) · สัญญาจำนองรายปีของบริษัทที่ต่ออายุวันนี้มีงวดปีหน้าและแสดงเฉพาะยอดที่ยังต้องชำระ
> นอกรีโป: Claude เริ่มรับงานเอกสารบัญชีรายเดือนผ่าน FlowAccount แทนการสร้างระบบบัญชีเอง

## งานที่ทำ

### 1. Dashboard แยกรายรับดอกเบี้ยตามเจ้าของเงินทุน

- **เปลี่ยนอะไร:** ใต้แถวตัวเลขหลักมีการ์ดใหม่ 2 ช่อง "สัญญาของบริษัท" กับ "สัญญาของนายทุน" แต่ละช่องแสดงจำนวนสัญญาที่ยังมีผล วงเงิน ดอกเบี้ยที่ชำระแล้ว ดอกเบี้ยตามสัญญาต่อเดือนและต่อปี และยอดหักล่วงหน้าวันทำสัญญา · ช่อง "ประเภทรายได้บริษัท" ในหน้าแก้ไขลูกค้ามีค่าที่สาม "เงินทุนของบริษัท · ดอกเบี้ยเข้าบัญชีบริษัท (ไม่มี Advance)"
- **ทำไม:** ค่าเดิม "รับดอกเบี้ยแทน (ไม่มี Advance)" ไม่ได้แปลว่าเงินของบริษัท มีสัญญาเงินนายทุนใช้ค่านี้อยู่ ถ้าใช้ค่านี้แยกฝั่ง ตัวเลขฝั่งบริษัทจะผิด และถ้าย้ายสัญญานั้นไปเป็นค่าคอมมิชชั่น ระบบจะคิด Advance 2% ให้ทั้งที่ไม่มี จึงเพิ่มค่าใหม่แทนการเปลี่ยนความหมายของค่าเดิม
- **ผล:** เทสต์ใหม่ 4 ข้อ (ตัวเลขสมมติ) รวมอยู่ใน `npm run test:interest-rate` ผ่าน 16 ข้อ · เทสต์การชำระ 63 ข้อผ่าน · build ผ่าน · ยอดสองฝั่งรวมกันเท่ากับยอดรวมเดิมเมื่อคำนวณกับข้อมูลจริง · ข้อความใหม่อยู่ในไฟล์ JS ของเว็บจริงแล้ว · ยังไม่ได้เปิดหน้าหลังล็อกอินดูด้วยตา
- commit `87232fe` · `58351b1` (commit หลังแก้รูปแบบขึ้นบรรทัดของ 2 ไฟล์ที่ commit แรกทำเพี้ยน เนื้อหาโค้ดไม่เปลี่ยน)

### 2. สัญญาจำนองรายปีของบริษัท: ต่ออายุหนึ่งปี และงวดปีหน้าแสดงยอดที่ยังต้องชำระ (ทำนอกรีโป · แก้ข้อมูล)

- **เปลี่ยนอะไร:** สัญญาที่บริษัทปล่อยเงินเองถูกตั้งเป็นประเภท "เงินทุนของบริษัท" · เพิ่มงวดของปีถัดไปและเลื่อนวันครบสัญญาออกไปหนึ่งปีตามบันทึกข้อตกลงที่ลงนามวันนี้ · จัดสรรเงินที่รับวันนี้ใหม่โดยยอดรวมเท่าเดิม: งวดปีแรกเป็นเงินรับจริงบวกรายการยกเว้นส่วนที่หักล่วงหน้าวันทำสัญญา ส่วนที่เก็บล่วงหน้าของปีถัดไปย้ายไปเป็นการชำระครั้งแรกของงวดปีหน้า
- **ทำไม:** เมนูลูกค้าไม่แสดงงวดถัดไปเพราะตารางชำระมีงวดเดียว · ระบบใช้ยอดต่องวดเดียวกันทุกงวด งวดปีหน้าจึงจะขึ้นยอดเต็มปีทั้งที่เก็บล่วงหน้าไปแล้วส่วนหนึ่ง เจ้าของให้แสดงยอดที่เหลือจริงตั้งแต่ตอนนี้
- **ผล:** ตัวคำนวณยอดของระบบอ่านข้อมูลจริงได้ งวดปีแรก "ครบ" งวดปีหน้า "ชำระไม่ครบ" เหลือเท่ายอดที่ตกลง · สำรองข้อมูลก่อนแก้ไว้ในโฟลเดอร์ backups นอกรีโป 2 ชุด · ยังไม่ได้เปิดเมนูลูกค้าดูด้วยตา
- **ทำนอกรีโป:** เขียนฐานข้อมูลโดยตรงตามคำสั่งเจ้าของ ไม่มี commit

### 3. งานเอกสารบัญชีรายเดือนผ่าน FlowAccount (ทำนอกรีโป)

- **เปลี่ยนอะไร:** เรียนแพตเทิร์นจากโฟลเดอร์เอกสารบัญชีของเครื่องเก่า แล้วบันทึกค่าใช้จ่ายประจำเดือนพฤศจิกายน 5 รายการใน FlowAccount · ทำหน้า "รายละเอียดและหลักฐานการจ่ายชำระเงิน" เป็น PDF และรวมชุดส่งสำนักงานบัญชีรอบแรก
- **ทำไม:** เจ้าของทำงานชุดนี้ด้วยมือทุกเดือนและอยากลดภาระ
- **ข้อจำกัดที่เจอ:** ตัวเชื่อม FlowAccount สร้างเอกสารได้อย่างเดียว แก้หรือยกเลิกไม่ได้ · ค่าใช้จ่ายที่มีหัก ณ ที่จ่ายไม่ออกหนังสือรับรองให้ · ใบแจ้งหนี้ที่สร้างผ่านตัวเชื่อมพิมพ์หัวเป็นใบกำกับภาษี ซึ่งสำนักงานบัญชีไม่รับ เจ้าของจึงแก้บนเว็บเอง · Word บนเครื่องนี้สั่งงานอัตโนมัติไม่ได้ จึงสร้าง PDF ผ่านเบราว์เซอร์แทน
- **ผล:** ชุดส่งบัญชียังไม่ครบ ขาดหนังสือรับรองหัก ณ ที่จ่ายและใบเสร็จจากผู้รับเงิน · เปิดตรวจหน้าตา PDF แล้ว 2 จาก 5 รายการ

### 4. ใบแจ้งหนี้ ใบเสร็จ และบันทึกข้อตกลงเพิ่มเติมของสัญญาจำนองรายปี (ทำนอกรีโป)

- **เปลี่ยนอะไร:** ตรวจใบแจ้งหนี้และใบเสร็จเทียบกับสัญญาเดิม พบเลขอ้างอิงที่ดิน เลขประจำตัว และที่อยู่ไม่ตรงในใบหนึ่ง เจ้าของแก้แล้ว · กรอกข้อมูลที่มีหลักฐานลงในบันทึกข้อตกลงเพิ่มเติม และทำฉบับที่สองจากฉบับที่เจ้าของแก้เป็นต้นแบบ · แก้ข้อความในบัญชีแนบท้ายให้บอกว่าดอกเบี้ยปีถัดไปเก็บล่วงหน้าแล้วเท่าไร เหลือเท่าไร
- **ทำไม:** เจ้าของต่อสัญญาสองฉบับในวันเดียวกันและต้องการเอกสารที่ตัวเลขตรงกันทุกใบ
- **ผล:** ตรวจด้วยการอ่านข้อความกลับจากไฟล์ ไม่ได้เปิดดูหน้าตาใน Word

## การตัดสินใจของเจ้าของ

- **ระบบบัญชี:** ไม่สร้างระบบบัญชีของตัวเอง ใช้ FlowAccount ต่อ โดยให้ Claude ทำงานเอกสารแทน
- **ค่าใช้จ่ายเดือนพฤศจิกายน:** ให้ Claude สร้างครบทุกรายการ (ไม่เลือกทางที่เจ้าของสร้างเองเฉพาะรายการที่ต้องออกหนังสือรับรองหัก ณ ที่จ่าย)
- **สัญญาของบริษัท:** มีเฉพาะสัญญาจำนองรายปีสองฉบับ สัญญาอื่นทั้งหมดเป็นของนายทุน
- **งวดปีหน้า:** ให้ระบบแสดงยอดที่เหลือจริงตั้งแต่ตอนนี้ (ไม่เลือกทางที่ปล่อยให้ขึ้นยอดเต็มแล้วค่อยยกเว้นส่วนต่างตอนรับเงิน)
- **วันลงนาม:** ผู้กู้สองรายเป็นญาติกัน จึงทำบันทึกข้อตกลงพร้อมกันในวันเดียว
