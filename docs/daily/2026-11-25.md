## งานที่ทำ

### 1. เอกสารบัญชีของเดือนนี้ (ทำนอกรีโป)

- **เปลี่ยนอะไร:** ตรวจสลิปและเอกสารสแกนที่เจ้าของใส่มา แยกหน้า หมุนหน้า จัดเข้าโฟลเดอร์ของแต่ละรายการ ทำหน้ารายละเอียดการชำระเงิน บันทึกค่าใช้จ่ายในโปรแกรมบัญชี และรวมเป็นไฟล์ชุดส่งบัญชีสี่รายการ พร้อมชุดเอกสารรายรับของเดือน
- **ทำไม:** เจ้าของทำงานนี้เองทุกเดือนและใช้เวลามาก จึงมอบให้ Claude ทำโดยให้ผลออกมาเหมือนชุดที่เจ้าของทำเองทุกจุด
- **ผล:** สี่รายการปิดแล้ว อีกสามรายการรอเอกสารที่ต้องมีลายเซ็นหรือใบเสร็จจากหน่วยงาน · พบไฟล์สแกนผิดเดือนหนึ่งไฟล์ จึงไม่จัดเข้าและแจ้งเจ้าของ

### 2. เครื่องมือออกเอกสารซ้ำรายเดือน (ทำนอกรีโป)

- **เปลี่ยนอะไร:** ย้ายเครื่องมือออกใบแจ้งหนี้และใบเสร็จของผู้ให้เช่ามาเครื่องนี้ ให้รันเลขเอกสาร วันที่ และวันครบกำหนดตามเดือนเอง · ทำตัวสร้างใบขออนุมัติเบิกเงินจากแม่แบบของเจ้าของ
- **ทำไม:** เอกสารพวกนี้รูปแบบเดิมทุกเดือน เปลี่ยนแค่เลข วันที่ และยอด · เจ้าของต้องนำใบขออนุมัติเบิกเงินไปเบิกกับบริษัทตามรอบต้นเดือน จึงต้องออกได้ทันทีที่มีสลิป
- **ผล:** ลองสร้างใบขออนุมัติเบิกเงินของรายการที่เจ้าของเซ็นไปแล้ว ข้อความตรงกับฉบับของเจ้าของ

### 3. กล่องรับเอกสารบัญชีทางเทเลแกรมและ LINE

- **เปลี่ยนอะไร:** รูปหรือไฟล์ที่เจ้าของส่งเข้าห้องบอท AssetX หรือส่งต่อเข้าบัญชี LINE ทางการ ถูกเก็บเข้าที่เก็บไฟล์ปิดทันทีพร้อมข้อความตอบรับในเทเลแกรม เมื่อเครื่องของเจ้าของเปิด คำสั่งหนึ่งคำสั่งดึงไฟล์ลงโฟลเดอร์กล่องรับเอกสารนอกรีโป
- **ทำไม:** เจ้าของต้องการส่งเอกสารทางแชตแล้วให้ระบบทำต่อเอง และไม่ต้องการเปิดคอมค้างไว้ สลิปที่บริษัทส่งให้มักมาทาง LINE
- **ผล:** ขึ้นระบบและพิสูจน์ด้วยสลิปจริงแล้วทั้งสองช่องทาง ทาง LINE รับเฉพาะบัญชีของเจ้าของ เพราะลูกค้าส่งสลิปเข้าบัญชีเดียวกัน ระหว่างตั้งค่าพบว่าบัญชี Vercel มีสองโปรเจกต์บนรีโปเดียวกัน และการกดนำขึ้นใหม่ไปลงที่โปรเจกต์เก่า จึงสั่งนำขึ้นใหม่ที่โปรเจกต์จริงแทน ข้อจำกัด: ระบบกันไฟล์ซ้ำได้เฉพาะในช่องทางเดียวกัน สลิปใบเดียวที่ส่งสองช่องทางจะถูกจับตอนจัดเข้าโฟลเดอร์

### 4. ตัวเตือนงานเอกสารบัญชีทางเทเลแกรม

- **เปลี่ยนอะไร:** ข้อความเตือนเข้าห้องบอทเวลาเก้าโมงเช้า: รอบเบิกแรกสามวันต้นเดือน รอบเบิกที่สองสำหรับรายการที่ตกหล่นสองวันก่อนเส้นตาย และเอกสารที่ยังขาดของเดือนช่วงกลางเดือน ข้อความบอกรายการที่ค้างและจำนวนวันที่เหลือ
- **ทำไม:** เจ้าของต้องนำใบขออนุมัติเบิกเงินไปเบิกกับบริษัทตามรอบ และขอให้เตือนกันลืม
- **ผล:** ขึ้นระบบแล้ว ลองส่งข้อความจริงเข้าห้องบอทได้ รายการที่เตือนมาจากไฟล์สถานะที่เครื่องของเจ้าของส่งขึ้นไป เพราะระบบบนเว็บมองไม่เห็นโฟลเดอร์ในเครื่อง ข้อจำกัด: ยังไม่ได้เห็นตัวตั้งเวลาทำงานจริง ครั้งแรกคือต้นเดือนหน้า และเวลาอาจคลาดได้ราวหนึ่งชั่วโมง
- commits: `4ff23ce` · `d3286c4`

### 5. งานตรวจเอกสารประจำวันบนเครื่องเจ้าของ

- **เปลี่ยนอะไร:** งานประจำของ Windows เวลาแปดโมงครึ่ง (เครื่องปิดอยู่จะทำตอนเปิดเครื่อง) ดึงไฟล์ที่ส่งทางแชต ดูว่ามีไฟล์ใหม่ไหมรวมทั้งที่เจ้าของวางเอง ถ้ามีจึงเรียก Claude แบบไม่มีหน้าต่างมาอ่าน จัดเข้าโฟลเดอร์ของรายการ อัปเดตรายการที่ยังขาด และส่งสรุปเข้าเทเลแกรม
- **ทำไม:** เจ้าของอยากให้ Claude เข้ามาตรวจเองทุกวัน เพื่อรู้ว่าเอกสารถูกใส่เข้ามาแล้วโดยไม่ต้องเปิดแชตบอก
- **ผล:** ลองทั้งชุดหนึ่งรอบด้วยสลิปซ้ำ: อ่านออกว่าเป็นรายการไหน รู้ว่าซ้ำ จึงไม่จัดซ้ำและไม่ลบ แล้วส่งสรุปได้ ใช้เวลาราวหนึ่งนาที งานนี้ถูกจำกัดให้อ่าน จัดไฟล์ และรายงานเท่านั้น ไม่เขียนทับ ไม่ลบ ไม่สร้างเอกสาร และไม่บันทึกในโปรแกรมบัญชี ข้อจำกัด: ยังไม่ออกใบขออนุมัติเบิกเงินเอง
