# สรุปประจำวัน · 29 ต.ค. 2569

> วันที่หน้าภาษีเลิกเป็นเกาะ: แท็บ "รีไฟแนนซ์ย้ายทุน" ดึงข้อมูลจากสัญญาลูกค้าในระบบได้เอง และระบบเริ่มเก็บ "ราคาประเมินราชการ" ต่อแปลงโฉนดเป็นครั้งแรก พร้อมอุดช่องว่างในหน้าวงเงินเพิ่ม (ปุ่มเลื่อนงวด สลิป) และแยกเงินรับจริงออกจากค่าตอบแทนหักล่วงหน้าบนแดชบอร์ด ทุก commit ขึ้น GitHub และ Vercel แล้วตอน 17:09

## ภาพรวม

- หน้าภาษี → รีไฟแนนซ์ย้ายทุน กด "ดึงจากสัญญาลูกค้าในระบบ" แล้วช่องเงินต้น อัตรา วันที่ ยอดหักล่วงหน้า ดอกเบี้ยที่รับแล้ว เติมให้เองพร้อมหมายเหตุที่มาของแต่ละค่า
- หน้าลูกค้า → โฉนดที่ดิน มีช่อง "ราคาประเมินราชการ (กรมธนารักษ์)" ต่อแปลง ระบบคูณเนื้อที่ให้ และเสนอราคาจากหน้าประเมินถ้าโฉนดเลขเดียวกันเคยประเมินไว้
- หน้าวงเงินเพิ่มได้ปุ่ม 📅 เลื่อนงวด แสดงสลิป และยอดเริ่มต้นตรงกับดอกเบี้ยวงเงินเพิ่ม (ไม่ใช่ของสัญญาหลัก)
- ทุกงวดของสัญญาหลักมีบรรทัด "อีก N วัน / เกิน N วัน" เหมือนวงเงินเพิ่ม
- แดชบอร์ด: "ดอกเบี้ยที่ชำระแล้ว" เหลือเฉพาะเงินที่รับจริงตามสลิป ค่าตอบแทนที่หักไว้ล่วงหน้าแยกไปอีกช่อง
- ปุ่ม "📄 ส่งออก PDF สรุปสัญญา" บนแดชบอร์ด แทนการรันสคริปต์

## งานที่ทำ

### 1. หน้าภาษีเชื่อมกับสัญญาลูกค้าและผลประเมิน
- **เปลี่ยนอะไร:** แท็บ "รีไฟแนนซ์ย้ายทุน" เลือกลูกค้าแล้วระบบเติมเงินต้น อัตรา วันทำสัญญา (อนุมานจากรายการหักล่วงหน้า) เดือน/ยอดหักล่วงหน้า ดอกเบี้ยที่รับแล้ว จำนวนโฉนด และยอดไถ่ที่จดไว้ วงเงินเพิ่มไม่ถูกรวมเข้าเงินต้นหลัก (คิดปิดยอดแยกจากวันเริ่มของแต่ละวงเงิน ไปไว้ใน "ค่าใช้จ่ายอื่น") ผลประเมินที่เลือกด้านบนส่งเข้าแท็บด้วยปุ่ม ไม่ใช่ effect แท็บอื่นก็รับราคาประเมินจาก dropdown ได้ · แก้ป้ายแท็บที่โชว์ "?????" (encoding หลุด) เป็น "รีไฟแนนซ์ย้ายทุน" · ปุ่มในฟอร์มใช้สไตล์เดียวกับปุ่มหัวหน้า
- **ทำไม:** เจ้าของอยากให้ 8 เครื่องคิดเลขในหน้าภาษีทำงานร่วมกัน และใช้แท็บ 1+2 หาแนวทางหาทุนใหม่หรือคำนวณให้ลูกค้าใหม่โดยไม่ต้องคัดลอกตัวเลขข้ามหน้า
- **อ้างอิง:** commit `a85b3b3` · `8b5b6eb` · `cb8babe` · `5acfb66`

### 2. ราคาประเมินราชการต่อแปลงโฉนด
- **เปลี่ยนอะไร:** โฉนดแต่ละแปลงของลูกค้าเก็บ บาท/ตร.ว. + สิ่งปลูกสร้าง + วันที่อ้างอิง (`govPrice`, `buildingValue`, `govPriceDate` ใน `customers.deeds[]`) แก้ไขแบบ inline ในหน้าลูกค้า ระบบแปลง ไร่-งาน-วา เป็น ตร.ว. และรวมมูลค่าต่อแปลง/ต่อลูกค้า หัวข้อโฉนดโชว์ยอดรวมหรือ "x/y แปลง" ถ้ายังไม่ครบ · รีไฟแนนซ์ย้ายทุนใช้ยอดนี้เติม "ราคาประเมินราชการรวม" เมื่อครบทุกแปลง
- **ทำไม:** ก่อนหน้านี้ระบบไม่มีที่เก็บราคาประเมินราชการเลย การ prefill รีไฟแนนซ์จึงเติมช่องนี้ไม่ได้
- **ผล:** รีวิวแบบหาข้อผิดพลาดเจอ 4 จุดและแก้ก่อนใช้จริง: บันทึกทีละแปลงโดยอ่านข้อมูลล่าสุดก่อนเขียน (กันราคาแปลงอื่นหายเมื่อบันทึกจากสองเครื่อง) · โฉนดที่ไม่มีเนื้อที่ต้องกรอก ไร่-งาน-วา ก่อนบันทึก · ยกเลิกแล้วค่าที่พิมพ์ไม่ค้าง · ราคาที่เสนอจากหน้าประเมินต้องจังหวัดตรงกัน · เทสต์ `npm run test:deed-assessment` ผ่าน
- **อ้างอิง:** commit `180b636` · `e752654`

### 3. หน้าวงเงินเพิ่ม: เลื่อนงวด สลิป และยอดเริ่มต้น
- **เปลี่ยนอะไร:** งวดวงเงินเพิ่มมีปุ่ม 📅 เลื่อน (เก็บวันเดิมและหมายเหตุ, งวดใกล้ครบกำหนดคิดจากวันที่จริงไม่ใช่ลำดับในอาร์เรย์) แสดงบรรทัดสลิป/วันจ่าย/หมายเหตุเหมือนสัญญาหลัก และหน้าต่างสลิปใช้ยอดดอกเบี้ยวงเงินเพิ่มเป็นค่าเริ่มต้น การเลื่อนที่ UPDATE ไม่โดนแถว (RLS/ถูกลบ) จะฟ้องแทนที่จะโชว์ว่าสำเร็จ
- **ทำไม:** เจ้าของพบว่าหน้าวงเงินเพิ่มไม่มีปุ่มเลื่อนและไม่มีที่ใส่สลิป ทั้งที่สัญญาหลักมีมานาน
- **อ้างอิง:** commit `2dce3da` · `dab7c5e`

### 4. บรรทัด "อีก N วัน" บนทุกงวดของสัญญาหลัก
- **เปลี่ยนอะไร:** ทุกงวดในตารางสัญญาหลักมีบรรทัดนับถอยหลัง/เกินกำหนด และ "ชำระเมื่อ <วันที่>" สำหรับงวดที่จ่ายแล้ว
- **ทำไม:** เจ้าของชอบตัวบอกจำนวนวันในหน้าวงเงินเพิ่ม และขอให้ใส่ให้สัญญาหลักของทุกคน
- **อ้างอิง:** commit `da795c1`

### 5. แดชบอร์ดแยกเงินรับจริงออกจากค่าตอบแทนหักล่วงหน้า
- **เปลี่ยนอะไร:** รายการชำระที่เป็นการหักค่าตอบแทนในวันทำสัญญาติดธง `slip_id = ADVANCE_DEDUCTION` แดชบอร์ดไม่นับรายการเหล่านี้ใน "ดอกเบี้ยที่ชำระแล้ว" และกราฟ 6 เดือน แต่ลิสต์ไว้ใต้ "ค่าตอบแทนหักล่วงหน้าที่บันทึก" หน้าต่างชำระล่วงหน้ามีช่องติ๊ก "หักจากยอดเบิกจ่ายวันทำสัญญา (ไม่มีเงินโอน)" สำหรับสัญญาใหม่
- **ทำไม:** หลังย้ายยอดหักล่วงหน้าเข้าตารางงวด ตัวเลขดอกเบี้ยที่ชำระแล้วบนแดชบอร์ดกลืนยอดเหล่านั้นเข้าไป เจ้าของต้องการเห็นเงินจริงที่รับมาแยกจากยอดที่หักไว้ (ส่วนหน้าลูกค้าแสดงแบบเดิมได้)
- **นอกรีโป:** ตรวจสอบตัวเลขย้อนหลังแล้วแก้ข้อมูลใน Supabase 2 ครั้งตามที่เจ้าของอนุญาต: จัดประเภทงวดที่จ่ายล่วงหน้าในวันเดียวกันของลูกค้ารายหนึ่งเป็นการชำระปกติ และบันทึกการชำระ 3 งวดที่ลืมลงไว้ของอีกราย
- **อ้างอิง:** commit `1a1f60b`

### 6. ส่งออก PDF สรุปสัญญาจากแดชบอร์ด
- **เปลี่ยนอะไร:** โมเดลรายงานและ HTML ย้ายไป `src/lib/contractSummaryReport.js` ให้สคริปต์ Node และเว็บใช้รูปแบบเดียวกัน ปุ่ม "📄 ส่งออก PDF สรุปสัญญา" บนแดชบอร์ดเปิดรายงาน A4 แนวนอนในแท็บใหม่แล้วเรียก Save as PDF ให้เอง (ตั้งชื่อไฟล์ให้ ตัดหัว/ท้ายของ Chrome) ข้อมูลเป็นข้อมูลสดเสมอ
- **ทำไม:** เจ้าของอยากกดส่งออกจากหน้าเว็บโดยตรง ไม่ต้องรันสคริปต์
- **ผล:** เทสต์ `npm run test:contract-summary` 8 กรณีผ่าน
- **อ้างอิง:** commit `53ead4e`
