# ประเภทเอกสารสิทธิ์และข้อจำกัดการทำธุรกรรม

เจ้าของขอเมื่อ 13 พ.ย. 2569: "ระบบเรายังไม่มีประเภทของโฉนด … รวมถึงข้อจำกัดในการทำธุรกรรม"

## คะแนนความเสี่ยงไม่เปลี่ยน

`computeValuation` ยังคิดคะแนนเอกสารจาก `TITLE_TYPES` เดิม โดย `effectiveTitleType(form)` แปลงประเภทเอกสาร + ภาระเป็นค่าเดิม:

- โฉนด / ห้องชุด: ปลอดภาระ 0 · ติดจำนองเดิม 3
- น.ส.3 ก: 5
- น.ส.3 / น.ส.3 ข / ใบไต่สวน: 8
- เอกสารอื่นทั้งหมด หรือภาระรุนแรง: 18

ข้อมูลเก่าที่มีแค่ `titleType` ได้คะแนนเท่าเดิมทุกค่า (มีเทสต์) ต่างจากเดิมเฉพาะร่างที่ประเภทย่อยบอก "ที่ดินเปล่า (น.ส.3)" หรือ "(ส.ค.1)" แต่เลือก "โฉนด" ไว้ ซึ่งตอนนี้คิดตามประเภทย่อย

## กติกาเวลาแก้

- ทุกข้อต้องมี `refs` ที่ชี้ไป `DEED_SOURCES` · official = อ่านตัวบทหรือหน้าหน่วยงานรัฐแล้ว · ข้อที่ยังไม่พบหนังสือกรมที่ดินยืนยัน เขียนว่า "ตีความ" หรือ "ยังไม่พบ" ในข้อความ และติด `c: 'secondary'`
- ห้ามใส่ดอกเบี้ย วงเงิน หรือเบอร์ของบริษัท (รีโปสาธารณะ · เทสต์ตรวจให้)
- ส.ป.ก. และโฉนดเพื่อการเกษตรเปลี่ยนตามนโยบายบ่อย: ตรวจข่าวแล้วแก้ `DEED_KNOWLEDGE_CHECKED`
- ทดสอบ `npm run test:deed-types` (และ `npm run test:research` ถ้าแก้คลังความรู้)

## ยังยืนยันไม่ได้ (ถามสำนักงานที่ดินเมื่อเจอเคสจริง)

1. สำนักงานที่ดินรับจดขายฝาก/จำนองบนที่ดินที่มีแค่ ส.ค.1 หรือไม่ — ระบบถือว่าไม่ได้ (คู่มือกรมที่ดินไม่นับ ส.ค.1 เป็นที่ดินที่จำนองได้)
2. จำนองใหม่บน น.ส.3 / น.ส.3 ข ต้องประกาศ 30 วันด้วยหรือไม่ — อ่านจากรายการยกเว้นในกฎกระทรวง ฉบับที่ 7 ข้อ 6 ว่าต้องประกาศ
3. ขายฝากห้องชุดต้องมีใบปลอดหนี้หรือไม่ และ พ.ร.บ.ขายฝาก 2562 ครอบคลุมห้องชุดที่ใช้อยู่อาศัยหรือไม่ — ระบบแนะนำให้ทำไว้ก่อน
4. ระหว่างมีพระราชกฤษฎีกากำหนดเขตเวนคืน ยังจดขายฝาก/จำนองได้หรือไม่
5. ผู้จัดการมรดกขายฝาก/จำนองที่ดินมรดกได้แค่ไหน และต้องให้ทายาทยินยอมหรือไม่
