# คลังรีเสิร์ช AssetX

เจ้าของสั่งเมื่อ 9 พ.ย. 2569 ว่า "เก็บข้อมูลที่ทำรีเสิร์ชไว้เป็นฐานข้อมูลในการปรับปรุงพัฒนาระบบของเราให้ดียิ่งขึ้น ทั้งในด้านการออกแบบ การตลาด และเชิงวิชาการ" และ "ทำงานบนเครื่องนี้เป็นหลัก… เก็บไว้บนเครื่องนี้ก็ได้ ไม่ต้องขึ้นไปบนเซิร์ฟเวอร์"

## อยู่ที่ไหน

คลังเป็น Obsidian vault บนคอมสำนักงาน อยู่นอกรีโป จึงไม่ขึ้น GitHub หรือเซิร์ฟเวอร์

- **ที่อยู่ค่าเริ่มต้น:** `<โฟลเดอร์แม่ของรีโป>/AssetX Knowledge/Research/คลังรีเสิร์ช AssetX/` ตั้งที่อื่นได้ด้วย `ASSETX_RESEARCH_LIBRARY_DIR` ใน `.env.local`
- **เหตุผลที่ไม่เก็บในรีโป:** รีโปเป็นสาธารณะ ข้อความโพสต์ คลิป และแอดของเพจอื่น รวมทั้งตัวอย่างดิบ ห้ามขึ้น GitHub
- **สิ่งที่ระบบใช้งานจริง:** อยู่ในรีโปตามเดิม คลังเก็บที่มา เหตุผล และข้อมูลดิบที่ขึ้นรีโปไม่ได้

| ใช้งานจริง (รีโป) | เรื่อง |
|---|---|
| `research/hook_patterns.json` | สูตร hook |
| `research/knowledge_base.json` | ข้อกฎหมายและค่าธรรมเนียม |
| `research/social_watch.json` | เพจที่เฝ้า |
| `src/lib/posterFree.js` และไฟล์ที่เกี่ยวข้อง | กติกาโปสเตอร์ |

**กติกาของไฟล์:**
- ไฟล์ที่ขึ้นต้น `อัตโนมัติ -` ระบบเขียนทับทุกครั้ง ถ้าจะแก้ ให้แก้ที่ไฟล์ต้นทางในรีโป
- ไฟล์อื่นเป็นโน้ตที่เขียนเอง ระบบไม่แตะ

## รันเมื่อไร

- **อัตโนมัติ:** `npm run research -- run` ทำเองทุก 7 วัน รอบเดียวกับบทเรียน hook
- **สั่งเอง:** `npm run research -- library` (ใส่ `--no-snapshot` เพื่อข้ามสำเนา)
- **กู้สำเนา:** `restoreBundle(fs.readFileSync(<ไฟล์ .json.gz>))` ใน `server/research/library.js` คืน `{ created_at, files: { path: เนื้อไฟล์ } }`

## ข้อจำกัด

- **สำเนาอยู่ในเครื่องเดียวกัน:** กันเผลอลบหรือเขียนทับได้ แต่กันคอมเสียไม่ได้ เจ้าของเลือกเก็บในเครื่อง ถ้าจะกันคอมเสีย ให้คัดลอกโฟลเดอร์คลังไปไดรฟ์อื่นเป็นครั้งคราว
- **ห้ามข้อมูลลูกค้า:** ห้ามใส่ข้อมูลลูกค้า เลขโฉนด เบอร์โทร หรือข้อมูลสัญญาจริงในคลัง (กติกาของ vault)
- **ข้อความของเพจอื่น:** ผ่านตัวลบข้อมูลบุคคลแล้ว และใช้ศึกษาเท่านั้น ห้ามลอกลงโพสต์เรา
